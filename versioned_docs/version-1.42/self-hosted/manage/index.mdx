These guides cover the day-to-day operation of an Okteto Self-Hosted instance, from upgrades to troubleshooting:

- [Upgrade](self-hosted/manage/upgrade.mdx): upgrade your Okteto instance to a new version of the Helm chart.
- [Argo CD](self-hosted/manage/argocd.mdx): install and upgrade Okteto with an Argo CD Application.
- [Okteto License](self-hosted/manage/okteto-license.mdx): get your license key and install it.
- [Backup and Restore](self-hosted/manage/backup-restore.mdx): recover your Okteto instance after a failure.
- [Custom Resource Definitions](self-hosted/manage/crds.mdx): the CRDs that Okteto installs in your cluster.
- [Air-Gapped Networks](self-hosted/manage/air-gapped.mdx): install Okteto in a network without internet access.
- [Troubleshooting](self-hosted/manage/troubleshooting.mdx): answers to common issues when you install, upgrade, or operate Okteto.
- [Diagnostics](self-hosted/manage/diagnostics.mdx): collect a support bundle with the diagnostics tool.
- [Uninstalling Okteto](self-hosted/manage/uninstall-okteto.mdx): remove Okteto from your cluster.
