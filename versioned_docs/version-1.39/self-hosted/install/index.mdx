The installation guides deploy the Okteto Helm chart with default values, which is enough for an evaluation. Before you give your team access to your Okteto instance, configure the parts that a production installation needs:

- [Wildcard certificate](self-hosted/install/certificates/index.mdx): replace the self-signed certificate that Okteto creates by default for the Okteto UI, the Okteto Build Service, the Okteto Registry, and the endpoints of your application environments.
- [Okteto Registry storage](self-hosted/install/okteto-registry-storage/index.mdx): store the images of the Okteto Registry in your cloud provider's object storage.
- [Authentication](self-hosted/install/auth/index.mdx): sign people in with your company's identity provider.
- [GitHub integration](self-hosted/install/github.mdx): give your developers access to your private GitHub repositories with a GitHub App.
- [BuildKit High Performance](self-hosted/install/buildkit-high-performance.mdx): size and scale the Okteto Build Service for fast builds, tests, and deployments.
- [Volume Snapshots](self-hosted/install/volume-snapshots.mdx): initialize the persistent volumes of an environment from a Volume Snapshot.
