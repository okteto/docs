---
title: Authentication
description: The authentication providers that Okteto supports to verify user identity.
---

Okteto verifies user identity through an authentication provider.
Your authentication configuration decides which users can access Okteto and how they log in.

Okteto supports the following authentication providers:

- [Azure Active Directory](self-hosted/install/auth/azure-ad.mdx)
- [Bitbucket](self-hosted/install/auth/bitbucket.mdx)
- [GitHub](self-hosted/install/auth/github.mdx)
- [GitLab](self-hosted/install/auth/gitlab.mdx)
- [Google](self-hosted/install/auth/google.mdx)
- [Okta](self-hosted/install/auth/okta.mdx)
- [OpenID Connect](self-hosted/install/auth/openid-connect.mdx)
- [Token](self-hosted/install/auth/token.mdx)

> Are we missing your favorite identity provider? Open a feature request in the [Okteto Community](https://community.okteto.com/t/about-the-feature-requests-category/28) and let us know!

Okteto also provides a single-user authentication method based on a [token](self-hosted/install/auth/token.mdx), for initial evaluations.
