Each of these guides installs it on one platform, with the default values and a basic configuration:

- [Install Okteto in DigitalOcean Kubernetes](get-started/install/digitalocean-doks.mdx)

- [Install Okteto in Nutanix Kubernetes Platform](get-started/install/nutanix-nkp.mdx)

## Supported Browsers

The Okteto UI supports these browsers:
- **Google Chrome**: Last 8 versions
- **Mozilla Firefox**: Last 8 versions
- **Microsoft Edge**: Last 8 versions
- **Safari**: Last 2 major versions (macOS only)

The Okteto UI is designed for desktop and doesn't support mobile browsers.

In air-gapped environments, make sure every user has one of the supported browser versions.

## Troubleshooting

The [troubleshooting page](self-hosted/manage/troubleshooting.mdx) covers the common issues when you install and operate Okteto. If you need more help, [contact support](https://okteto.com/support).

## Uninstalling Okteto

To uninstall Okteto, delete its Helm release:

```bash
helm uninstall okteto
```

This deletes Okteto, but not the resources created while using it, such as namespaces, accounts, and deployments.
