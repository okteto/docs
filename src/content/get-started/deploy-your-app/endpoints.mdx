Okteto serves the Ingress objects deployed in your Namespace on public HTTPS endpoints. The Movies app defines one Ingress, `movies`, in its Helm chart.

This page uses the [Movies app](https://github.com/okteto/getting-started), deployed with `okteto deploy` as described in [Deploy](deploy.mdx). Run the commands from the root of your clone of the repository.

## The Ingress

The `chart/templates/ingress.yaml` file of the Movies app defines the Ingress:

```yaml title="chart/templates/ingress.yaml"
apiVersion: networking.k8s.io/v1
kind: Ingress
metadata:
  name: movies
  annotations:
    dev.okteto.com/generate-host: "true"
spec:
  rules:
    - http:
        paths:
          - path: /
            pathType: Prefix
            backend:
              service:
                name: frontend
                port:
                  number: 80
          - path: /api
            pathType: Prefix
            backend:
              service:
                name: api
                port:
                  number: 8080
```

The `dev.okteto.com/generate-host: "true"` annotation makes Okteto generate the host of the Ingress in the [Okteto Subdomain](self-hosted/helm-configuration.mdx#subdomain): `<ingress-name>-<namespace>.<okteto-subdomain>`. For the `movies` Ingress in the `cindy` Namespace, with the Okteto Subdomain `okteto.example.com`, the host is `movies-cindy.okteto.example.com`. Requests to `/` go to the `frontend` service and requests to `/api` go to the `api` service. [Endpoints for Ingress](core/endpoints/ingress.mdx) describes the generated hostnames and the other annotations.

If you deploy with Docker Compose, define your endpoints in the [`endpoints` section of your Docker Compose file](reference/docker-compose.mdx#endpoints-object-optional) instead.

## Listing the Endpoints

`okteto deploy` prints the endpoints when it finishes. To list them at any time, run:

```bash
okteto endpoints
```

```bash
 i  Using cindy @ okteto.example.com as context
 i  Endpoints available:
  - https://movies-cindy.okteto.example.com
  - https://movies-cindy.okteto.example.com/api
```

The Okteto UI shows the same endpoints next to your deployment.

## Calling the Endpoints

The `frontend` service returns the page of the Movies app:

```bash
curl https://movies-cindy.okteto.example.com
```

```html
<!DOCTYPE html>
<html>
  <head>
    <title>Movies</title>
    ...
```

The `api` service returns the movies that the `seed` job loaded into MongoDB:

```bash
curl https://movies-cindy.okteto.example.com/api/movies
```

```json
[{"_id":260513,"id":260513,"vote_average":7.6,"original_title":"Incredibles 2","backdrop_path":"/mabuNsGJgRuCTuGqjFkWe1xdu19.jpg", ...
```

Open `https://movies-cindy.okteto.example.com`, with your Namespace and Okteto Subdomain, in your browser to see the Movies app:
