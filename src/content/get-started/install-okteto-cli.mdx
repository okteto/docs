The Okteto CLI is the [open-source](https://github.com/okteto/okteto) command-line tool you use to build, deploy, test, and develop your applications on Okteto.

## Installing the Okteto CLI

Follow the steps for your operating system.

### macOS and Linux

```bash
curl https://get.okteto.com -sSfL | sh
```

To install a specific version, set the `OKTETO_VERSION` environment variable:

<CodeBlock language="bash">
  {`curl https://get.okteto.com -sSfL | OKTETO_VERSION=${variables.cliVersion} sh`}
</CodeBlock>

You can also install it with [Homebrew](https://brew.sh/), from the Okteto tap:

```bash
brew install okteto/cli/okteto
```

The Okteto tap installs Okteto's prebuilt binary.

:::warning

Don't install from Homebrew Core with `brew install okteto`. That formula compiles the Okteto CLI from source with Homebrew's Go toolchain, which Okteto doesn't control, and that can lead to inconsistencies.

:::

### Windows

Download [`okteto.exe`](https://downloads.okteto.com/cli/stable/okteto.exe) and add it to your `PATH`.

You can also install it with [Scoop](https://scoop.sh/):

```bash
scoop install okteto
```

:::tip

To update the Okteto CLI with Scoop, you might need to run `scoop unhold okteto & scoop update okteto` or `scoop uninstall okteto & scoop install okteto`.

:::

### GitHub

You can also download the binary from the [GitHub releases](https://github.com/okteto/okteto/releases), or build it from the source code.
