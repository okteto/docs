The **Develop on Okteto** button deploys your repository in Okteto with one click. Add it to the `README` file of the repository, to its documentation, or to any page that renders HTML, instead of a list of steps to deploy the application. Whoever clicks it logs in to your Okteto instance and gets the **Deploy Dev Environment** dialog with your repository already selected.

This button deploys [the Movies app](https://github.com/okteto/movies) in the `okteto.example.com` instance:

[![Develop on Okteto](https://okteto.com/develop-okteto.svg)](https://okteto.example.com/deploy?repository=https://github.com/okteto/movies)

## Requirements

The button works with any public Git repository that Okteto can deploy, that is, with an [Okteto Manifest](application-environments/index.mdx#okteto-manifest) or a Docker Compose file. To check that it deploys, [deploy it from the Okteto UI](application-environments/deploy.mdx#deploying-from-the-okteto-ui) first.

## Adding the Button

The button is a link to the `/deploy` path of your Okteto instance. Replace `okteto.example.com` with the domain of your instance in the snippets on this page.

### Inferring the Repository

In the `README` file of a public GitHub repository, the button doesn't need any parameter: Okteto infers the repository and the branch from the page that the click comes from. This only works for public repositories on `https://github.com`.

```markdown
[![Develop on Okteto](https://okteto.com/develop-okteto.svg)](https://okteto.example.com/deploy)
```

The same button in HTML:

```html
<a href="https://okteto.example.com/deploy">
  <img src="https://okteto.com/develop-okteto.svg" alt="Develop on Okteto">
</a>
```

The image is also available as a PNG file, at `https://okteto.com/develop-okteto.png`.

### Setting the Repository

Anywhere else, such as a blog post, your documentation, or a repository outside GitHub, set the `repository` parameter, and optionally the `branch`:

```markdown
[![Develop on Okteto](https://okteto.com/develop-okteto.svg)](https://okteto.example.com/deploy?repository=https://github.com/okteto/movies&branch=main)
```

The same button in HTML:

```html
<a href="https://okteto.example.com/deploy?repository=https://github.com/okteto/movies&branch=main">
  <img src="https://okteto.com/develop-okteto.svg" alt="Develop on Okteto">
</a>
```

## Parameters

The `/deploy` link takes these parameters:

- `repository`: the URL of the repository to deploy. Without it, Okteto infers the repository from the page that the click comes from, if it's a public GitHub repository.
- `branch`: the branch to deploy. It defaults to the default branch of the repository.
- `vars`: variables that the deploy commands get as environment variables, as a URL-encoded JSON list. For example, `vars=[{"name":"THEME","value":"dark"},{"name":"LANG","value":"en"}]` sets `THEME=dark` and `LANG=en`.
- `filename`: the path of the Okteto Manifest, relative to the root of the repository. Without it, Okteto looks for an Okteto Manifest or a Docker Compose file in the usual locations.
