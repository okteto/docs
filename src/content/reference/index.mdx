**References** has two kinds of pages: the ones you look things up in, with every command, field, endpoint, and variable that Okteto supports, and the ones that explain in detail how a part of Okteto works.

- [Okteto CLI](reference/okteto-cli.mdx): every command and flag of the Okteto CLI.
- [Okteto Manifest](reference/okteto-manifest.mdx): every field of `okteto.yaml`.
- [Docker Compose](reference/docker-compose.mdx): the Docker Compose fields that Okteto supports, and the extensions it adds.
- [Feature Flags](reference/feature-flags.mdx): the environment variables that turn on new and experimental behavior of the Okteto CLI.
- [Okteto API](reference/okteto-api.mdx): where to find every endpoint of the Okteto API, and how to authenticate your requests.
- [Develop on Okteto Button](reference/develop-on-okteto-button.mdx): the button that deploys a repository in Okteto with one click, and the parameters of its link.
- [How Remote Execution Works](reference/remote-execution.mdx): how Okteto runs your deploy, destroy, and test commands in a container inside the cluster.
- [How Smart Builds Work](reference/smart-builds.mdx): how Okteto reuses an image that someone already built from the same code.
