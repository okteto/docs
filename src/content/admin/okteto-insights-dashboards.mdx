The Okteto Insights dashboards are Grafana dashboards that show how your Okteto instance is used: the activity of your users, the duration and the error rate of builds, deploys, and tests, and the CPU and memory usage of your nodes, Namespaces, and pods. They read the [metrics that Okteto Insights exposes](reference/okteto-insights-metrics.mdx), and Okteto publishes them in the [insights-dashboards repository](https://github.com/okteto/insights-dashboards), with a Prometheus and Grafana setup to deploy them.

## Activity Dashboard

The Activity dashboard tracks the adoption of Okteto across your organization:

- Total active users.
- `okteto up` sessions.
- Active Namespaces and Preview Environments.

<Image
  src={require("@site/static/img/insights-activity-dashboard.png").default}
  alt="The Activity dashboard of Okteto Insights"
  width="800"
/>

## Build Service Dashboard

The Build Service dashboard shows the performance and the resource usage of the [Okteto Build Service](admin/build-service.mdx). Use it to find resource bottlenecks, to see how builds spread across the BuildKit pods, to size those pods, and to troubleshoot slow builds.

For the whole Build Service, it shows:

- The number of BuildKit pods.
- The active builds across all the BuildKit pods.

<Image
  src={require("@site/static/img/insights-build-service-dashboard.png").default}
  alt="The Build Service dashboard of Okteto Insights"
  width="800"
/>

For each BuildKit pod, it shows:

- The active builds.
- The CPU and memory usage over time.
- CPU pressure and throttling.
- Disk read and write operations, and I/O pressure.
- The available inodes, which builds need to succeed.

<Image
  src={require("@site/static/img/insights-build-service-pods-dashboard.png").default}
  alt="The panels of the Build Service dashboard for each BuildKit pod"
  width="800"
/>

## Cluster Nodes Dashboard

The Cluster Nodes dashboard shows the CPU and memory usage of the nodes of your cluster as a whole, next to the CPU and memory requests of their pods. Pods that use less than they request waste infrastructure, and pods that use more can be throttled or evicted, and leave the cluster unbalanced. Use this dashboard to find out whether your cluster has too many or too few resources, and whether its workloads are balanced across the nodes.

The Images dashboard shows the duration of your image builds over time, and how often they succeed or fail. It has two filters:

- **Development Environment**: the application environments to show data for.

## Namespace Dashboard

The Namespace dashboard shows the CPU and memory that a Namespace uses. Its **Namespace** filter selects the Namespace to show data for. It has these panels:

- **CPU requests and usage:** the CPU that the pods of the Namespace request, next to the CPU they use. A gap between the two points to resources that are over-allocated or under-used.
- **Memory requests and usage:** the same comparison for memory.
- **Pods:** the number of active pods over time, to relate a spike in usage to a change in the number of pods.

The [Resource Manager](admin/resource-manager.mdx) sets the CPU and memory requests of your services from this usage.

## Nodes Dashboard

The Nodes dashboard shows the CPU and memory usage of one node. Its **Node Name** filter selects the Kubernetes node. Use it to troubleshoot the performance of a node, and to check how workloads are distributed across nodes.

<Image
  src={require("@site/static/img/insights-nodes-dashboard.png").default}
  alt="The Nodes dashboard of Okteto Insights"
  width="800"
/>

## Pods Dashboard

The Pods dashboard shows the CPU and memory usage of each pod, to find problems such as memory leaks. It has two filters:

- **Namespace**: the Namespace to show data for.
- **Development Environment**: the application environment to show data for, among the ones of that Namespace.

<Image
  src={require("@site/static/img/insights-pods-dashboard.png").default}
  alt="The Pods dashboard of Okteto Insights"
  width="800"
/>

## Test Dashboard

The Test dashboard shows the runs of [Okteto Test](application-environments/okteto-test.mdx) over time: the average time a test takes to pass, and how often tests pass or fail. It has two filters:

- **Development Environment**: the application environment to show data for.
- **Test**: the name of the test to show data for.

<Image
  src={require("@site/static/img/insights-test-dashboard.jpg").default}
