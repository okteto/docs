**Integrations** groups the sections of the Admin Dashboard that connect your Okteto instance with other tools: Git, your identity provider, Okteto Insights, automations, container registries, and cloud providers.

- [General Integrations](admin/integrations.mdx): the Okteto SSH key for Git, the Okteto Insights token, the OpenID Connect details, and Okta user deprovisioning.
- [Admin Access Tokens](admin/admin-access-tokens.mdx): tokens with Admin permissions for automations and the Okteto API.
- [Registry Credentials](admin/registry-credentials/index.mdx): access to your private container registries.
- [Cloud Credentials](admin/cloud-credentials/index.mdx): access to your cloud provider for the deploy commands, without static keys.
