**Admin > Installation** is a checklist of the tasks that complete the setup of your Okteto instance after you install the Helm chart:

- **Okteto License:** your [license key](self-hosted/manage/okteto-license.mdx), how many users it allows, and when it expires.
- **Domain:** the subdomain where Okteto exposes the Okteto UI and your application environments.
- **Certificates:** a [wildcard certificate](self-hosted/install/certificates/index.mdx) instead of the self-signed one.
- **Custom Authentication:** your company's [identity provider](self-hosted/install/auth/index.mdx).
- **Okteto Registry External Storage:** [external storage for the Okteto Registry](self-hosted/install/okteto-registry-storage/index.mdx).

Each task has a **See Docs** button that opens the guide that explains it, and the completed tasks are grouped under **Completed Tasks**. You can skip a task that doesn't apply to your instance, and include it again later. The badge next to **Installation** in the Admin menu shows how many tasks are still pending.

Okteto shows this section when the `unsupported.installationBoard.enabled` Helm value is `true`, which is the default.
