**Settings** groups the sections of the Admin Dashboard that apply to every application environment of your Okteto instance: how the Okteto CLI and deployments behave, shared variables, the Garbage Collector, the Resource Manager, and the SSH hosts that Okteto trusts.

- [Command Line (CLI)](admin/cli.mdx): the default execution mode and the minimum version of the Okteto CLI.
- [Deployments](admin/deployments.mdx): whether redeploying or destroying an application includes its dependencies.
- [Admin Variables](admin/admin-variables.mdx): variables for every application environment of your instance.
- [Garbage Collector](admin/cleanup.mdx): when idle Namespaces and Preview Environments sleep and get deleted.
- [Resource Manager](admin/resource-manager.mdx): the CPU and memory requests of your services, set from their real usage.
- [Known Hosts](admin/ssh-known-hosts.mdx): the SSH hosts that Okteto trusts for Git.
