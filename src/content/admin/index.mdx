# Okteto Administration

## Administration Capabilities

Okteto's administration features give Admins tools and insights to manage users, security, and resource usage across your Development Environments.


## Explore Our Administration Features

### Okteto Admin Dashboard
The [Admin Dashboard](admin/dashboard.mdx) is a web UI for your Okteto instance. Manage users, monitor activity, and oversee environments all in one place.

### Agent Skills Rollout
Pre-install the Okteto agent skills for every developer in your organization. Adding the marketplace to Claude Code's managed settings keeps the plugin current without anyone running install commands, so agents have the Okteto CLI knowledge from their first session. The [managed settings configuration](agentic/index.mdx#updating-the-plugin) covers the setup.

### Build Service
The [Build Service](admin/build-service.mdx) view monitors Okteto Build performance and resource utilization. View real-time metrics for CPU pressure, memory usage, IO pressure, and active builds across your BuildKit pods.
Configure thresholds to optimize build performance and ensure consistent build times for your development teams.

### Okteto Catalog
Discover and deploy applications from the [Okteto Catalog](admin/catalog.mdx). Simplify the setup of tools and services for your development teams with pre-configured environment templates.

### Resource Manager
The [Resource Manager](admin/resource-manager.mdx) automates your CPU and memory resource requests to ensure your workloads stay balanced and your cluster resources are optimized.

### Resource Cleanup
Optimize your environments with Okteto's [Resource Cleanup](admin/cleanup.mdx) feature. Automatically sleep unused resources to maintain a lean and efficient development workflow.

### Okteto Insights
Delve into [Okteto Insights](admin/okteto-insights.mdx) for detailed analytics on resource usage, build and deployment metrics, enabling data-driven decisions to boost productivity.

### Private Repositories
Securely manage your code with [Private Repositories](admin/private-repositories/github.mdx) in Okteto. Configure GitHub or Private Keys to access your code providers.

### SSH Known Hosts
[SSH Known Hosts](admin/ssh-known-hosts.mdx) centrally manage trusted SSH hosts for Git operations used by Okteto’s installer jobs and remote executions. Prevent host verification failures and enforce organization-wide trust for Git providers.

### Registry Credentials
[Registry Credentials](admin/registry-credentials/index.mdx) let you pull images from a private registry in addition to [Okteto's Container Registry](core/container-registry.mdx).

### Cloud Credentials
[Cloud Credentials](admin/cloud-credentials/index.mdx) dynamically configure Okteto's connection to AWS and GCP, eliminating the need for developers to manage static credentials.

### Custom Installer Image for Your Pipelines
Tailor Okteto to fit your unique deployment needs with [Custom Installer Images](admin/custom-installer-image.mdx), allowing your tools, frameworks, or custom configurations.

## Start Administering Like a Pro
Dive into each feature to unlock the full administrative potential of Okteto. Whether you're looking to streamline your setup, secure your projects, or gain valuable insights, Okteto Administration provides the tools you need to manage your cloud-native development environment effectively.
