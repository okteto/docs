The Admin Dashboard of the Okteto UI is where Admins manage your Okteto instance: its users and Namespaces, the settings that apply to every application environment, and the integrations with other tools. Open it from **Admin** in the main menu of the Okteto UI.

Only users with the Admin role see the Admin Dashboard. The first user who logs in to a new Okteto instance becomes its first Admin. To make another user an Admin, change their role in [Users](admin/users.mdx), or add the `dev.okteto.com/super: "true"` label to their service account in Kubernetes.

The Admin Dashboard has three groups of sections, and each section has a page in these docs:

- [Cluster Management](admin/cluster-management.mdx): the state of your instance, its users, nodes, Namespaces, and Preview Environments.
- [Settings](admin/settings.mdx): the configuration that applies to every application environment.
- [Integrations](admin/integrations-overview.mdx): the connections with Git, identity providers, container registries, cloud providers, and automations.
