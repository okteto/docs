## Deploy Execution Mode

**Deploy Execution Mode** sets where `okteto deploy` runs the commands of the `deploy` section by default: **Remote**, in the cluster with [Remote Execution](reference/remote-execution.mdx), or **Local**, on the machine that runs the Okteto CLI. Remote is the default, and local execution is deprecated.

## Minimum Accepted Version

**Minimum Accepted Version** sets the oldest Okteto CLI version that developers can use. The options are relative to the Okteto CLI version that your instance ships. For example, if it ships {variables.cliVersion}:

| Option | Accepted versions |
|---|---|
| **Any Version** | Every version |
| **Current Version** | {`${cliMajor}.${cliMinor}.0`} and later |
| **Previous Version** | {`${cliMajor}.${cliMinor - 1}.0`} and later |
| **Two Previous Versions** | {`${cliMajor}.${cliMinor - 2}.0`} and later |

When a developer runs an older version, the Okteto CLI commands fail with an error that asks them to update. The check applies to [Okteto CLI 3.2.0](https://github.com/okteto/okteto/releases/tag/3.2.0) and later.
