**Admin > Previews** lists every [Preview Environment](previews/index.mdx) in your Okteto instance, whoever created it. From there, Admins put Preview Environments to sleep, wake them up, delete them, and mark them as persistent.

## Filtering and Searching Previews

These filters narrow down the list of Preview Environments:

- **Search**: finds Preview Environments by name.
- **Repository**: filters by one or more repositories. You can search the list of repositories.
- **Owner**: filters by the user who created the Preview Environment. You can search the list of users.
- **Status**: filters by status, such as active, sleeping, or error.
- **Updated**: filters by the time of the last update:
  - Last Hour
  - Last 24 Hours
  - Last 7 Days
  - Last 30 Days
  - Last 90 Days

You can combine several filters.

## Preview Table Columns

The table shows these columns for each Preview Environment:

- **Name**: the Preview Environment's name. Click it to see its details.
- **Repository**: the repository with the code, with a link to it in your Git provider.
- **PR**: a link to the pull request.
- **Owner**: the user who created the Preview Environment.
- **Status**: the Preview Environment's current status, for example active, sleeping, or deploying.
- **Last Updated**: when the Preview Environment last changed.

## Managing Preview Environments

The menu at the end of each row has these actions:

- **Delete**: deletes the Preview Environment. It's only available if you have the permissions to delete it, and not for persistent Preview Environments, which you have to unmark first.
- **Wake Up**: wakes up a sleeping Preview Environment.
- **Put To Sleep**: puts an active Preview Environment to sleep to save resources. It's disabled for persistent Preview Environments.
- **Persistent**: marks the Preview Environment as persistent, so it's never deleted or put to sleep for inactivity. The [Garbage Collector](admin/cleanup.mdx) doesn't delete it either, because it stays active.

:::tip
A persistent Preview Environment stays available until someone deletes it. Mark long-running demos and environments that must always be reachable as **Persistent**.
:::
