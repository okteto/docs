**Admin > Catalog** lists the applications that Admins preconfigure for developers. Each Catalog item sets a repository, a branch, an Okteto Manifest path, and environment variables, so developers deploy an application environment from the Okteto UI without configuring any of them.

<Image
  src={require("@site/static/img/admin-catalog.png").default}
  alt="The Catalog section of the Admin Dashboard, with a table of Catalog items, their names and repository URLs, an Edit button on each row, and the Add Item button"
/>

Only Admins can manage the Catalog.

:::note
A **Read-only** tag next to a Catalog item means that the item is defined with a Custom Resource Definition (CRD). You can't change it from the Admin Dashboard: update its CRD instead, as [Catalog items in the CRDs reference](self-hosted/manage/crds.mdx#catalog-items) explains.
:::

## Creating the Catalog

You create and manage Catalog items in one of two ways:

1. [From the Admin Dashboard](#create-and-manage-catalog-items-via-the-dashboard)
1. [With Custom Resource Definitions (CRDs)](self-hosted/manage/crds.mdx#catalog-items)

### Managing Catalog Items from the Admin Dashboard {#create-and-manage-catalog-items-via-the-dashboard}

Go to **Admin > Catalog** and click **Add Item** to open the **Add Catalog Item** form.

#### Adding an Application to the Catalog {#add-an-application-to-the-catalog}

The form adds a Catalog item: a preconfigured application that developers deploy with one click, from its repository and the settings you provide. It has these fields:

- **Name** (required)
- [**Description**](#add-a-description)
- **Repository URL** (required)
- [**Default Branch**](#define-a-default-branch)
- [**Manifest Path**](#define-a-manifest-path)
- [**Environment Variables**](#add-environment-variables)

Fill in the ones you need and click **Save**.

  <Image
    src={require("@site/static/img/admin_catalog_view_add+1.33.png").default}
    alt="Add a repository to the Catalog"
    width="900"
  />
</p>

#### Description {#add-a-description}

**Description** tells developers what they get when they deploy the Catalog item. Developers see it under the item's name when they choose what to deploy, in place of the repository URL, and above the deploy options once they select the item. It's optional.

#### Default Branch {#define-a-default-branch}

**Default Branch** is the branch selected by default when a developer deploys the Catalog item.

You can add several Catalog items for the same **Repository URL**, each with a different **Default Branch**.

#### Manifest Path {#define-a-manifest-path}

**Manifest Path** is the path to your Okteto Manifest in the repository. It's optional.

#### Environment Variables {#add-environment-variables}

**Environment Variables** sets the variables that Okteto passes to every deployment of the Catalog item, with the values that developers start from when they deploy it. They're optional. As with **Default Branch**, you can add several Catalog items for the same **Repository URL**, each with different environment variables.

Every variable needs a name. The **See more** menu (**⋯**) at the end of each variable's row has these options:

- [**Multi-value**](#multi-value-variables): gives developers a list of values to pick from.
- [**Description**](#variable-descriptions): explains the variable to developers.
- **Remove**: removes the variable.

##### Multi-Value Variables {#multi-value-variables}

A multi-value variable has a list of values, and developers pick one of them when they deploy the Catalog item, instead of typing a value. To create one, check **Multi-value** in the variable's **See more** menu, and add the values with **Add value**. The field of a multi-value variable shows its default value and how many values it has: click it to add, change, or remove values.

<p align="center">
  <Image
    src={require("@site/static/img/admin_catalog_multi_value+1.51.png").default}
    alt="Editing the values of a multi-value variable"
    width="800"
  />
</p>

- The first value is the default: it's selected when a developer deploys the Catalog item.
- A multi-value variable has from 2 to 50 values. Values can't be empty or repeated, and Okteto trims the spaces around them.
- A multi-value variable with a single value is saved as a regular variable.

To make it a regular variable again, uncheck **Multi-value**. The variable keeps its default value.

##### Variable Descriptions {#variable-descriptions}

To explain what a variable is for, check **Description** in the variable's **See more** menu and type it in the field under the variable. Developers see it under the variable when they deploy or redeploy the Catalog item. Unchecking **Description** removes it.

A variable description has up to 120 characters, and it's shown as a single paragraph.

## Deploying from the Catalog {#deploy-a-dev-environment-from-your-catalog}

To deploy a Catalog item, go to **Namespaces**, click **Deploy Dev Environment**, and select **Catalog**.

The list shows every Catalog item with its [description](#add-a-description), or with its repository URL when it has none. The search matches names, descriptions, and repository URLs.

<p align="center">
  <Image
    src={require("@site/static/img/gc_deploy_dev_env+1.51.png").default}
    alt="The Catalog list with each item's description"
    width="800"
  />
</p>

Select an item to configure its deployment. The dialog shows the item's name and description, and these fields:

- **Repository**: the item's repository. To pick another item, click the **×** next to it, or click the **Catalog** tab.
- **Branch**: the branch to deploy, set to the item's [Default Branch](#define-a-default-branch).
- **Variables**: the item's [environment variables](#add-environment-variables), with their [descriptions](#variable-descriptions). Change their values, pick a value for each [multi-value variable](#multi-value-variables), or add your own variables.
- **Advanced Options**: the path to the Okteto Manifest, set to the item's [Manifest Path](#define-a-manifest-path).

<p align="center">
  <Image
    src={require("@site/static/img/gc_deploy_configure+1.51.png").default}
    alt="Configuring the deployment of a Catalog item"
    width="800"
  />
</p>

Click **Deploy** to deploy the application environment.

A multi-value variable shows its values in a dropdown, with the default value selected:

<p align="center">
  <Image
    src={require("@site/static/img/gc_deploy_multi_value+1.51.png").default}
    alt="Picking the value of a multi-value variable"
    width="800"
  />
</p>

When you redeploy an application environment that you deployed from the Catalog, the **Variables** section shows the values you deployed. Multi-value variables offer the values that the Catalog item has when you redeploy, and the value you deployed stays selected even if the item no longer has it.
