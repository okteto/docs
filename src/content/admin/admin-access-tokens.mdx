**Admin > Integrations > Admin Access Tokens** creates tokens that authenticate with Okteto with Admin permissions. They work like [Personal Access Tokens](application-environments/credentials/personal-access-tokens.mdx), but they aren't tied to a person, so they're the right choice for shared automations, such as the CI pipelines that deploy [Preview Environments](previews/index.mdx).

<Image
  src={require("@site/static/img/admin-access-tokens.png").default}
  alt="The Admin Access Tokens section of the Admin Dashboard, with a table of tokens"
/>

Okteto runs the automations that use an Admin Access Token as the [`okteto-bot` user](self-hosted/helm-configuration.mdx#oktetobotuser).

Use an Admin Access Token to authenticate the Okteto CLI in a pipeline, or to call the [Okteto API](reference/okteto-api.mdx), which [explains how to send the token](reference/okteto-api.mdx#authentication) with each request.
