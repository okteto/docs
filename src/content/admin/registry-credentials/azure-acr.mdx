Okteto pulls images from your private Azure Container Registry (ACR) with the [Registry Credentials](admin/registry-credentials/index.mdx) you configure in the Admin Dashboard. The commands on this page use the [Azure CLI](https://learn.microsoft.com/en-us/cli/azure/).

Configuring access to your private ACR takes three steps:

- Creating a user with access to your private ACR
- Getting the user's credentials
- Configuring the credentials in Okteto

## Step 1: Creating a user with access to your private ACR

Create a service principal with role-based access control. It needs:

- `scopes`: your Azure Container Registry's ID
- `role`: `acrpull`, for read access to your private ACR

List your container registries:

```bash
az acr list
```

Export your ACR's name, and a name for the service principal, as environment variables:

```bash
export ACR_NAME=<your-acr-name>
export SERVICE_PRINCIPAL_NAME=okteto-acr-pull
```

Get your ACR's ID with the [Azure CLI](https://learn.microsoft.com/en-us/cli/azure/acr?view=azure-cli-latest#az-acr-show):

```bash
ACR_REGISTRY_ID=$(az acr show --name $ACR_NAME --query "id" --output tsv)
```

Create the service principal with pull access with the [Azure CLI](https://learn.microsoft.com/en-us/cli/azure/azure-cli-sp-tutorial-2#create-a-service-principal-containing-a-password):

```bash
az ad sp create-for-rbac --name $SERVICE_PRINCIPAL_NAME --scopes $ACR_REGISTRY_ID --role acrpull
```

## Step 2: Getting the user's credentials

Get the service principal's `APP ID`:

```bash
APP_ID=$(az ad sp list --display-name $SERVICE_PRINCIPAL_NAME --query "[].appId" --output tsv)
```

Create a `PASSWORD` for that `APP ID`:

```bash
az ad sp credential reset --id $APP_ID
```

```bash
{
  "appId": "<<your-app-id>>",
  "password": "<<your-password>>",
  "tenant": "98e0e81b-dd65-4132-9d6c-ed2ac3e14e28"
}
```

Keep the values of `appId` and `password`: you enter them in Okteto in [Step 3: Configuring the credentials in Okteto](#step-3-configuring-the-credentials-in-okteto).

## Step 3: Configuring the credentials in Okteto

Go to **Admin > Integrations > Registry Credentials**, click **Add Credential**, and enter these values, as [Adding Registry Credentials](admin/registry-credentials/index.mdx#adding-registry-credentials) explains:

- **Type**: `Static`
- **Hostname**: your Azure Container Registry's login server, `ACR_NAME.azurecr.io`
- **Username**: the `appId` from [Step 2: Getting the user's credentials](#step-2-getting-the-users-credentials)
- **Password**: the `password` from [Step 2: Getting the user's credentials](#step-2-getting-the-users-credentials)
