Okteto pulls images from your private Google Artifact Registry with the [Registry Credentials](admin/registry-credentials/index.mdx) you configure in the Admin Dashboard. The commands on this page use the [gcloud CLI](https://cloud.google.com/sdk/docs/install).

Configuring access to your private Google Artifact Registry takes three steps:

- Creating a service account with access to your private Google Artifact Registry
- Getting the service account's credentials
- Configuring the credentials in Okteto

## Step 1: Creating a Service Account with Access to Your Private Google Artifact Registry

Export your Google Cloud project ID and the name you want for your service account:

```bash
export PROJECT_ID=<your-project-id>
export SA_NAME=<your-service-account-name>
```

Create the service account with the [gcloud CLI](https://cloud.google.com/sdk/gcloud/reference/iam/service-accounts/create):

```bash
gcloud iam service-accounts create ${SA_NAME} --project=${PROJECT_ID} --display-name="My Service Account for Okteto"
```

Add a policy that grants the service account read access to your private Google Artifact Registry:

```bash
gcloud projects add-iam-policy-binding ${PROJECT_ID} \
    --member=serviceAccount:${SA_NAME}@${PROJECT_ID}.iam.gserviceaccount.com \
    --role=roles/artifactregistry.reader
```

## Step 2: Getting the Service Account's Credentials

Create a key for the service account:

```bash
gcloud iam service-accounts keys create SA_KEY_FILE.json \
    --iam-account=${SA_NAME}@${PROJECT_ID}.iam.gserviceaccount.com
```

The command creates a file named `SA_KEY_FILE.json` with the credentials. You enter its content in Okteto in [Step 3: Configuring the credentials in Okteto](#step-3-configuring-the-credentials-in-okteto).

## Step 3: Configuring the Credentials in Okteto

Go to **Admin > Integrations > Registry Credentials**, click **Add Credential**, and enter these values, as [Adding Registry Credentials](admin/registry-credentials/index.mdx#adding-registry-credentials) explains:

- **Type**: `Static`
- **Hostname**: your private Google Artifact Registry's endpoint, for example `europe-west1-docker.pkg.dev`
- **Username**: `_json_key`
- **Password**: the content of `SA_KEY_FILE.json`

You can also set the **Username** to `_json_key_base64` and the **Password** to the Base64-encoded content of `SA_KEY_FILE.json`:

```bash
cat SA_KEY_FILE.json | base64
```
