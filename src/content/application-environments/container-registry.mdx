The Okteto Registry stores the container images and the Helm charts of your Okteto Namespaces. Each Namespace has its own space in the registry, and the applications deployed in a Namespace pull its images with no extra configuration.

## Pushing Images

[`okteto build`](application-environments/build-service.mdx) builds the images of the `build` section of your Okteto Manifest and pushes them to the Okteto Registry. For example, with this Okteto Manifest:

```yaml title="okteto.yaml"
build:
  api:
    context: api
```

```bash
okteto build
```

```console
 i  Using cindy @ okteto.example.com as context
 i  Building 'api/Dockerfile' in tcp://buildkit.okteto.example.com:443...
 ...
 ✓  Image 'registry.okteto.example.com/cindy/movies-with-helm-api:okteto' successfully pushed
```

The name of the image includes the registry of your Okteto instance, your Namespace, the name of your application, and the name of the image in your Okteto Manifest. You don't need to write it in your deploy commands: Okteto sets a variable with the name of each image. For the `api` image, it's `OKTETO_BUILD_API_IMAGE`:

```yaml title="okteto.yaml"
deploy:
  - helm upgrade --install movies chart --set api.image=${OKTETO_BUILD_API_IMAGE}
```

See [Okteto Variables](application-environments/okteto-variables.mdx#built-in-environment-variables-for-images-in-okteto-registry) for every variable of your images.

## Pulling Images

The images of the Okteto Registry are private. The applications deployed in a Namespace can pull the images of that Namespace without any credentials. To pull them from anywhere else, authenticate with the registry first, with the credentials described in [Pushing Helm Charts](#pushing-helm-charts).

## Pushing Helm Charts

The Okteto Registry also stores Helm charts, as OCI artifacts. The Okteto CLI doesn't push them for you: log in to the registry, package the chart, and push it with Helm.

The `deploy` commands of your Okteto Manifest get the credentials of the registry from the `OKTETO_REGISTRY_URL`, `OKTETO_USERNAME`, and `OKTETO_TOKEN` variables, and your Namespace from `OKTETO_NAMESPACE`:

```yaml title="okteto.yaml"
deploy:
  - helm registry login ${OKTETO_REGISTRY_URL} -u ${OKTETO_USERNAME} -p ${OKTETO_TOKEN}
  - helm package ./chart
  - helm push ./movies-api-0.1.0.tgz oci://${OKTETO_REGISTRY_URL}/${OKTETO_NAMESPACE}
```

To push a chart from your machine instead, get the same values from your Okteto context:

```bash
okteto context show --include-token
```

```console
{
    "name": "https://okteto.example.com",
    "username": "cindy",
    "token": "i3kDEh4FKqrJzY7e7Qamd8CfTTrjkPOTN5ftHoKl",
    "namespace": "cindy",
    "registry": "registry.okteto.example.com",
    ...
}
```

The `registry` field is the URL of the registry, `username` is your username, and `token` is your password.

## Pulling Helm Charts

To pull a chart from the Okteto Registry, log in to the registry and pull it with Helm:

```yaml title="okteto.yaml"
deploy:
  - helm registry login ${OKTETO_REGISTRY_URL} -u ${OKTETO_USERNAME} -p ${OKTETO_TOKEN}
  - helm pull oci://${OKTETO_REGISTRY_URL}/${OKTETO_NAMESPACE}/movies-api --version 0.1.0
```
