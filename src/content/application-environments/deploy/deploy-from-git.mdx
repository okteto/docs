The Okteto UI deploys an application environment from any Git repository with an [Okteto Manifest](application-environments/okteto-manifest.mdx) or a Docker Compose file, without the Okteto CLI. Okteto clones the repository and runs `okteto deploy` on it, in your current Namespace.

## Deploying a Repository

1. In the Namespace view of the Okteto UI, click **Deploy Dev Environment**.
2. Select **Git URL** as the source, and type the URL of the repository in **Repository URL**.
3. Optionally, type a **Branch**. It defaults to the main branch of the repository.
4. Optionally, add **Variables**, which your deploy commands get as environment variables, and set the **Okteto Manifest Path** in **Advanced Options** if your Okteto Manifest isn't at the root of the repository.
5. Click **Deploy**.

To deploy a private repository, select **GitHub** as the source after you connect your GitHub account, or use the repository's SSH URL. See [Deploy from private repositories](application-environments/deploy/from-private-repositories.mdx).

The Namespace view shows the application while it deploys, and its status changes to **Deployed** when it's ready, with its endpoints, repository, and branch:

## Redeploying

To deploy the latest code of the branch, or to change the branch, the variables, or the Okteto Manifest path, click **Redeploy** next to the application, change what you need, and click **Redeploy**:

<Image
  src={require("@site/static/img/redeploy-catalog+1.42.png").default}
  alt="The Redeploy Dev Environment dialog with the repository, the branch, three variables, and the Advanced Options section"
  width="600"
/>

If the application declares [dependencies](application-environments/okteto-manifest.mdx#dependencies), select **Include all direct dependencies** to redeploy them too. Admins set whether this option is selected by default in [**Admin > Deployments**](admin/deployments.mdx).

## Destroying

To destroy the application, click **Destroy** next to it and confirm. Okteto runs its `destroy` commands and deletes the resources it created, except its persistent volumes. You can't recover them afterwards, so back up any data you need first.

<Image
  src={require("@site/static/img/destroy-catalog+1.42.png").default}
  alt="The confirmation dialog to destroy the microservices-demo application, with the Include volumes option"
  width="450"
/>

The dialog has two options:

- **Include volumes:** also deletes the persistent volumes of the application.
- **Include all direct dependencies:** also destroys the applications that it declares as dependencies, so they don't keep running on their own. It only shows up for applications with dependencies.

## Develop on Okteto Button

To let anyone deploy your repository with one click, add a [Develop on Okteto button](application-environments/deploy/develop-on-okteto-button.mdx) to its `README` file.
