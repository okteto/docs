---

You deploy an application environment with [`okteto deploy`](reference/okteto-cli.mdx#deploy) from your machine, a CI pipeline, or a coding agent's sandbox. The Okteto UI deploys one too, without the Okteto CLI:

- [From the Catalog](application-environments/deploy/deploy-from-catalog.mdx): deploy one of the applications that your Admin added to the Catalog.
- [From a Git repository](application-environments/deploy/deploy-from-git.mdx): deploy any repository that has an Okteto Manifest or a Docker Compose file.
- [From private repositories](application-environments/deploy/from-private-repositories.mdx): connect your GitHub account, or use SSH, to deploy private repositories.
- [Develop on Okteto button](application-environments/deploy/develop-on-okteto-button.mdx): a button in your README that deploys the repository in one click.
