---

You deploy an application environment with [`okteto deploy`](reference/okteto-cli.mdx#deploy), from your machine, a CI pipeline, or a coding agent's sandbox. The Okteto UI deploys one too, without the Okteto CLI:

- [From the Catalog](application-environments/deploy/deploy-from-catalog.mdx): deploy one of the applications that your Admins added to the Catalog.
- [From a Git repository](application-environments/deploy/deploy-from-git.mdx): deploy any repository with an Okteto Manifest or a Docker Compose file, and redeploy or destroy it.
- [From private repositories](application-environments/deploy/from-private-repositories.mdx): deploy private repositories from your GitHub account, or over SSH.
- [Develop on Okteto button](application-environments/deploy/develop-on-okteto-button.mdx): a button in your `README` file that deploys the repository with one click.
