**Settings > Integrations** connects your GitHub account to Okteto. Once you connect it, the **Deploy** dialog of the Okteto UI lists your public and private repositories, and you can [deploy any of them](application-environments/deploy/from-private-repositories.mdx) as an application environment.

<Image
  src={require("@site/static/img/private-repositories-update-sidebar+1.32.png").default}
  alt="The Integrations section of the Settings, with the GitHub group and its Configure button"
/>

The **GitHub** group only appears when an Admin has [set up the GitHub integration](self-hosted/install/github.mdx) for your Okteto instance. Otherwise, the section says "There are no integrations available."

## Connecting Your GitHub Account

You connect your GitHub account once, and Okteto keeps your GitHub permissions across sessions.

1. In the Okteto UI, open **Settings > Integrations**.
1. Click **Connect** in the **GitHub** group, and authorize Okteto in the GitHub window that opens.
1. Click **Configure** to install the Okteto GitHub App in the accounts and organizations whose repositories you want to deploy. In the GitHub window, choose the accounts and the repositories, and follow the instructions to grant the permissions.

   <Image
     src={require("@site/static/img/private-repositories-enable.png").default}
     alt="GitHub dialog to install the Okteto App on your accounts and organizations"
     width="400"
   />

1. Click **Install & Authorize**. If you aren't an administrator of the organization, GitHub emails its administrators and waits for their approval to complete the installation.

   <Image
     src={require("@site/static/img/private-repositories-authorize.png").default}
     alt="GitHub dialog to install and authorize the Okteto App on your repositories"
     width="400"
   />

You can also start the connection from the **Deploy** dialog: select **GitHub** as the source, and click **Configure GitHub** next to the repository list.

## Adding or Removing Repositories

The **GitHub** group lists every account and organization where the Okteto GitHub App is installed, with its status: **Installed**, **Suspended**, or **Uninstalled**.

- To add or remove repositories of an account or an organization, click **Reconfigure** next to it, and change the repositories in the GitHub window that opens.
- To install the app in another account or organization, click **Configure**. Only the administrators of an organization can install the app in it.
- If an installation is suspended, click **Unsuspend**. If it's uninstalled, click **Reinstall**.

Even if an organization gives Okteto access to all its repositories, you only see the repositories that you can access in GitHub.
