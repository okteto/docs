**Settings** in the Okteto UI holds the configuration of your own account: how the Okteto CLI and your Kubernetes tools connect to Okteto, the tokens that authenticate your scripts and coding agents, your GitHub connection, and the variables that Okteto adds to every application environment you deploy. To open it, click **Settings** in the main menu of the Okteto UI.

- [Setup](user-settings/setup.mdx): download the Okteto CLI context and the Kubernetes credentials for your Okteto Namespaces, and choose the primary email of your account.
- [Personal Access Tokens](user-settings/personal-access-tokens.mdx): tokens that authenticate the Okteto CLI and calls to the Okteto API as you, in scripts, CI pipelines, and coding agents' sandboxes.
- [Integrations](user-settings/integrations.mdx): connect your GitHub account, and choose the repositories that Okteto can deploy.
- [Variables](user-settings/variables.mdx): your own Okteto Variables, which Okteto passes to the commands of every application environment you deploy.

For shared automations, such as the CI pipelines that deploy Preview Environments, an Admin creates [Admin Access Tokens](admin/admin-access-tokens.mdx) instead of Personal Access Tokens.
