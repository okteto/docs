The Okteto Registry can store your container images in DigitalOcean Spaces.

In this guide, `<<your-access-key-id>>` and `<<your-secret-key>>` refer to the access key ID and the secret key of the Spaces access key you want to use for the Okteto Registry.

Create a secret with the value of `<<your-secret-key>>` using the command below:

```bash
kubectl create secret generic okteto-registry-secret --namespace=okteto --from-literal=secretKey=<<your-secret-key>>
```

Then, add the following configuration to your Okteto Helm configuration file:

```yaml title="config.yaml"
registry:
  storage:
    provider:
      digitalocean:
        enabled: true
        region: <<your-space-region>>
        space:
          name: <<your-space-name>>
          accessKeyID: <<your-access-key-id>>
```

`<<your-space-region>>` is the region of your Space, as in its endpoint `<<your-space-region>>.digitaloceanspaces.com` (for example, `nyc3` or `ams3`).

Finally, [upgrade your Okteto instance](self-hosted/manage/upgrade.mdx) for the new configuration to be applied.
We recommend that you upgrade to the same version that you already have to minimize the changes and help you troubleshoot any issues.
