# Configure the Okteto Registry with external storage

The [Okteto Registry](application-environments/container-registry.mdx) supports the following storage drivers for your images:

- [Filesystem](self-hosted/install/okteto-registry-storage/filesystem.mdx)
- [Amazon S3 Bucket](self-hosted/install/okteto-registry-storage/aws-s3-bucket.mdx)
- [Azure Storage Container](self-hosted/install/okteto-registry-storage/azure-storage-container.mdx)
- [DigitalOcean Spaces](self-hosted/install/okteto-registry-storage/digitalocean-spaces.mdx)
- [Google Cloud Storage](self-hosted/install/okteto-registry-storage/google-cloud-storage.mdx)
