---
title: Okteto Registry with Filesystem storage
description: Configure the Okteto Registry to store container images in the filesystem or in a persistent volume.
sidebar_label: Filesystem
id: filesystem
---

The Okteto Registry can store your container images in the filesystem.

Depending on the type of storage you use, filesystem storage might limit your ability to scale up the registry.

To store the images in the container filesystem, set `filesystem.enabled` to `true` in your Helm configuration file.

To store the images in a PVC attached to the Okteto Registry, also set `filesystem.persistence.enabled` to `true`.
You can also customize the `storageClass` (optional) and the volume's `size` (defaults to 40Gi), or attach an existing persistent volume claim with `claimName`.

```yaml title="config.yaml"
registry:
  storage:
    filesystem:
      enabled: true
      persistence:
        enabled: true
        claimName: ""
        accessMode: ReadWriteOnce
        storageClass: ""
        size: 40Gi
```

[Upgrade your Okteto instance](self-hosted/manage/upgrade.mdx) to apply the new configuration.
Upgrade to the same version you already run: it keeps the changes to a minimum and makes any issue easier to troubleshoot.
